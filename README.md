# نظام ERP + نقطة بيع لمكتب التخليص الجمركي

نظام ويب متكامل لإدارة مكتب تخليص جمركي في سوريا، بواجهة عربية (من اليمين لليسار) وإنكليزية، يدعم الليرة السورية والدولار. **النسخة 0.2**.

## الجديد في 0.2
- **لوحة تحكم بحرية**: بحر وسفينة حاويات متحركة، تحية حسب الوقت، «ملخص اليوم» (يُكتب تلقائياً، ويمكن إعادة كتابته بالذكاء الاصطناعي)، بطاقات مؤشرات بأرقام متحركة واتجاه مقارنة بالشهر الماضي، تنبيهات ذكية ملوّنة.
- **5 ثيمات**: حسب النظام، فاتح، داكن، ملكي (كحلي وذهبي)، مخطط (Blueprint). ولغتين عربي/English بزر واحد.
- **تتبع الشحنات**: بحري/جوي/بري، مسار على الخريطة، مراحل وأحداث، صفحة تتبع عامة للعميل `/track` بدون تسجيل دخول.
- **مساعد ذكي (Claude)**: يجاوب عن المعاملات والشحنات وحسابات العملاء من بيانات النظام، يقترح رمز HS، ويقرأ البوليصة/الفاتورة (PDF أو صورة) ويعبّي المعاملة.
- **لوحة سير العمل** (سحب وإفلات)، **حاسبة الرسوم** (CIF + رسوم + تحويل لليرة)، **عروض الأسعار** مع تحويلها لفاتورة، **إرفاق ملفات** بالمعاملات، **سجل النشاطات**.
- لوحة أوامر `Ctrl+K` للبحث والإجراءات السريعة، `F2` لنقطة البيع، تأكيد أنيق بدل نوافذ المتصفح، يعمل على الموبايل.
- لا يوجد زكاة ولا ضريبة قيمة مضافة ولا رقم ضريبي (حقل «رقم بطاقة المستورد» بدلاً منه).

## تفعيل الذكاء الاصطناعي
أضف مفتاحك إلى `.env` ثم أعد التشغيل:
```
ANTHROPIC_API_KEY=sk-ant-...
```
بدون المفتاح يعمل النظام كاملاً، وتختفي ميزات المساعد فقط.

> نسب الرسوم الجمركية في جدول HS تجريبية للتوضيح، عدّلها من «الإعدادات» حسب التعرفة الرسمية النافذة.

## التشغيل على جهازك
المتطلبات: [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
cd customs-erp
cp .env.example .env        # وغيّر SESSION_SECRET لنص طويل عشوائي
npm install
npm run setup               # ينشئ قاعدة البيانات ويضيف بيانات تجريبية
npm run dev                 # ثم افتح http://localhost:3000
```

### حسابات الدخول التجريبية
| المستخدم | كلمة المرور | الدور |
|---|---|---|
| admin | admin123 | مدير النظام |
| accountant | 123456 | محاسب |
| broker | 123456 | مخلّص جمركي |
| cashier | 123456 | كاشير |

غيّر كلمات المرور من صفحة «المستخدمون» قبل الاستخدام الفعلي.

## النشر على الإنترنت (لفتحه من الجوال بدون Claude)
الطريقة المقترحة مجانية وما بتحتاج بطاقة: **Vercel** للموقع و**Neon** لقاعدة البيانات.

1. ادخل على [vercel.com](https://vercel.com/signup) واعمل حساب عن طريق **Continue with GitHub** (خطة Hobby المجانية).
2. اضغط **Add New → Project** واختر المستودع `customs-erp` ثم **Import**. لا تضغط Deploy بعد.
3. من **Environment Variables** أضف:
   - `SESSION_SECRET` = أي نص طويل عشوائي (30 حرف أو أكثر).
   - `ANTHROPIC_API_KEY` = مفتاحك (اختياري، لتفعيل المساعد الذكي).
4. اضغط **Deploy**. أول مرة رح يفشل لأنه ما في قاعدة بيانات، هذا طبيعي.
5. افتح المشروع ← تبويب **Storage** ← **Create Database** ← اختر **Neon (Postgres)** ← المنطقة **Frankfurt** (الأقرب لسوريا) ← **Connect**. هيك بيتضاف `DATABASE_URL` لحاله.
6. ارجع لتبويب **Deployments** ← على آخر نشر اضغط **⋯ → Redeploy**.
7. بيعطيك رابط مثل `customs-erp-xxxx.vercel.app`. افتحه وسجّل دخول بـ `admin / admin123` وغيّر كلمة المرور فوراً.

أول نشر بيعبّي بيانات تجريبية. أي تعديل بترفعه على GitHub بينشر لحاله.

### تثبيته على الجوال متل التطبيق
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

بيطلع أيقونة مرساة على الشاشة، وبيفتح بشاشة كاملة بدون شريط المتصفح.

> حجم الملف المرفوع للمعاملة حتى 4MB على الاستضافة (حد Vercel). الملفات بتنحفظ بقاعدة البيانات.

## التشغيل للإنتاج
```bash
npm run build
npm start
```
للعمل على PostgreSQL يكفي تضع رابطه في `DATABASE_URL` (يبدأ بـ `postgresql://`)، والنظام بيبدّل لحاله، ثم `npm run setup`.
